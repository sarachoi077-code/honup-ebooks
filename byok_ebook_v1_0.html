1장 · AI 키, 이게 뭔가요?

식당 회원카드와
같습니다

어려운 말로는 API 키(API Key)라고 부릅니다.
그냥 내 전용 출입증이라고 생각하면 됩니다.

비유
단골 식당에 회원카드를 내밀면
"아, 이 손님이구나" 하고 알아봅니다.
AI 서비스도 똑같습니다.
키를 보여주면 "이 사람이 요청한 거구나" 하고 처리해 줍니다.

회원카드가 있어야 혜택을 받듯, AI 서비스도 키가 있어야 사용할 수 있습니다. 키는 보통 알파벳·숫자가 섞인 긴 문자열입니다.

1장 · AI 키, 이게 뭔가요?

키가 곧
내 계량기

전기 계량기처럼, AI 키에는 내가 얼마나 썼는지가 기록됩니다.

요금 추적

내 키로 사용한 만큼만 청구됩니다. 다른 사람 사용량과 섞이지 않습니다.

사용량 제어

월 한도를 직접 설정할 수 있습니다. 한도를 넘으면 자동으로 멈춥니다.

서비스 분리

프로젝트별로 키를 따로 만들 수 있습니다. 어떤 서비스가 얼마나 썼는지 추적 가능.

BYOK(Bring Your Own Key)는 직역하면 "내 키를 가져온다"입니다. 서비스가 자체 키를 쓰는 대신, 내 키를 직접 입력해서 쓰는 방식입니다.

2장 · 왜 내 키를 써야 하나요?

3가지 이유

1

비용을 직접 통제한다

서비스가 AI 비용을 대신 내면, 그 비용은 구독료나 프리미엄 요금으로 청구됩니다. 내 키를 쓰면 실제 사용한 만큼만 AI사에 직접 냅니다. 대부분의 경우 훨씬 저렴합니다.

2

내 데이터가 서비스 서버를 거치지 않는다

BYOK 서비스는 대화 내용을 자체 서버에 저장하지 않습니다. 내 키로 직접 AI사에 전송됩니다. 민감한 사업 내용을 다룰 때 특히 중요합니다.

3

모델을 내가 고른다

Claude, GPT-4o, Gemini 중 어떤 모델을 쓸지 직접 선택할 수 있습니다. 서비스가 임의로 저렴한 모델로 교체할 수 없습니다.

2장 · 왜 내 키를 써야 하나요?

실제 비용 차이

같은 작업을 했을 때, 어떤 방식이 더 경제적인지 비교합니다.

방식 결제 구조 월 예상 비용 통제권
ChatGPT Plus 구독 월정액 고정 $20/월 없음
Claude Pro 구독 월정액 고정 $20/월 없음
BYOK (내 키 사용) 사용한 만큼만 실사용량 비례 완전 통제
로컬 AI (LM Studio) 없음 $0 (영구) 완전 통제

* BYOK 실제 비용은 모델 선택·사용량에 따라 다릅니다. 구독 대비 절감 여부는 사용 패턴에 따라 달라집니다.

3장 · 클라우드 AI 키 받는 법

3대 AI사
키 발급 안내

각 AI사 홈페이지에서 직접 발급받습니다.
회원가입 후 5분이면 완료됩니다.

AI사 모델명 무료 크레딧 발급 주소
Anthropic Claude Haiku · Sonnet · Opus 없음 (선불 충전) console.anthropic.com
OpenAI GPT 시리즈 없음 (선불 충전) platform.openai.com
Google Gemini 시리즈 무료 티어 있음 aistudio.google.com
중요 — 처음 충전 금액
Anthropic·OpenAI 모두 소액 선불 충전 후 사용합니다.
정확한 최소 충전액은 각 콘솔에서 확인하세요.
3장 · 클라우드 AI 키 받는 법

Anthropic (Claude)
키 발급 순서

1

console.anthropic.com 접속

Google 계정 또는 이메일로 가입합니다. 이메일 인증 완료 후 진행.

2

결제 수단 등록 및 크레딧 충전

Settings → Billing에서 신용카드를 등록하고 $5 이상 충전합니다. 카드 정보는 암호화 보관됩니다.

3

API Keys 메뉴에서 키 생성

좌측 메뉴 → API Keys → "Create Key" 버튼 클릭. 키 이름을 "byok-test" 같이 알아보기 쉽게 입력합니다.

4

키 복사 후 안전하게 보관

생성 직후 한 번만 전체가 표시됩니다. 반드시 복사해서 메모장 등에 저장하세요. 다시 볼 수 없습니다.

3장 · 클라우드 AI 키 받는 법

키 관리
3가지 원칙

키는 비밀번호보다 더 조심해야 합니다.
유출되면 내 돈이 나갑니다.

🔒 절대 공유 금지

카카오톡, 이메일, 노션 공개 페이지에 키를 붙여넣지 마세요. 캡처 이미지도 위험합니다.

💰 월 한도 설정

각 AI사 콘솔에서 월 지출 한도를 설정하세요. 혹시 유출되어도 피해를 제한할 수 있습니다.

🔄 의심되면 즉시 교체

키가 노출된 것 같다면 즉시 기존 키를 삭제하고 새 키를 발급하세요. 비용이 들지 않습니다.

주의
GitHub, 노션 공개 페이지, 블로그 코드 등에
키를 그대로 올리면 수십만 원의 피해가 발생한 사례가 있습니다.

완전 로컬

클라우드 AI는 인터넷을 통해 외부 서버에서 처리합니다.
로컬 AI는 내 컴퓨터 안에서 직접 처리합니다.

핵심 차이
클라우드: 인터넷 → AI사 서버 → 응답
로컬: 내 컴퓨터 → 바로 응답

요금 청구 서버가 없으니 비용도 없습니다.
4장 · 로컬 AI — LM Studio

LM Studio
4단계로 시작

코드 한 줄 없이 클릭만으로 로컬 AI를 실행합니다.

1

lmstudio.ai에서 무료 설치

Windows·Mac 모두 지원합니다. 설치 파일을 내려받아 실행하면 됩니다.

2

모델 선택 · 내려받기

검색창에서 모델을 골라 다운로드합니다. 내 RAM에 들어가는 크기를 보며 선택하세요. RAM 8GB → 7B 이하 / RAM 16GB → 13B 이하 권장.

3

Developer 탭 → "Start Server" 클릭

LM Studio가 내 컴퓨터 안에 AI 서버를 엽니다. 주소는 localhost:1234입니다.

4

BYOK 서비스에 주소 입력

WonGuardian 같은 BYOK 서비스의 설정창에 http://localhost:1234를 입력하면 연결 완료입니다.

4장 · 로컬 AI — LM Studio

클라우드 AI vs
로컬 AI

클라우드 AI (BYOK) 로컬 AI (LM Studio)
비용 사용량 비례 과금 0원 (영구)
인터넷 필요 없어도 됨
응답 속도 빠름 내 컴퓨터 성능에 따라
모델 성능 최신 고성능 중간 수준 (개인 PC 한계)
데이터 보안 AI사 서버로 전송 100% 로컬, 외부 전송 없음
설치 난이도 키 발급만 하면 됨 LM Studio 설치 + 모델 다운로드

처음 시작은 로컬 AI로 부담 없이 연습하고, 성능이 필요한 작업은 클라우드 AI 키를 쓰는 것이 실용적입니다.
