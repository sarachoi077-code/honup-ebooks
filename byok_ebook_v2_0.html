1장 · AI 키, 이게 뭔가요?

키가 곧
내 계량기

전기 계량기처럼, AI 키에는 내가 얼마나 썼는지가 기록됩니다.

요금 추적

내 키로 사용한 만큼만 청구됩니다. 다른 사람 사용량과 섞이지 않습니다.

사용량 제어

월 한도를 직접 설정할 수 있습니다. 한도를 넘으면 자동으로 멈춥니다.

서비스 분리

프로젝트별로 키를 따로 만들 수 있습니다. 어떤 서비스가 얼마나 썼는지 추적 가능.

키는 내 AI 계정과 연결된 고유 코드입니다. BYOK 서비스에 이 키를 입력하면, 해당 서비스를 통해 AI를 쓸 때 요금이 내 계정으로 직접 청구됩니다.

2장 · 왜 내 키를 써야 하나요?

3가지 이유

1

비용을 직접 통제한다

서비스가 AI 비용을 대신 내면, 그 비용은 구독료나 프리미엄 요금으로 청구됩니다. 내 키를 쓰면 실제 사용한 만큼만 AI사에 직접 냅니다. 가볍게 쓰는 달엔 $1도 안 나올 수 있습니다.

2

내 데이터가 서비스 서버를 거치지 않는다

LORITN·WonGuardian 같은 브라우저 직접 연결 방식의 BYOK 서비스는 대화 내용을 자체 서버에 저장하지 않습니다. 키와 대화가 내 브라우저에서 AI사로 직접 전송됩니다. 민감한 사업 내용을 다룰 때 특히 중요합니다.

3

모델을 내가 고른다

Claude, GPT-4o, Gemini 중 어떤 모델을 쓸지 직접 선택할 수 있습니다. 서비스가 임의로 저렴한 모델로 교체할 수 없습니다. 내 작업에 맞는 모델을 직접 결정합니다.

토큰 = AI의 단위
AI는 텍스트를 토큰(token) 단위로 처리합니다.
한국어는 영어보다 토큰을 더 많이 씁니다 (모델마다 차이 있음)
A4 1장 분량 ≈ 약 500~1,000토큰 (언어·모델에 따라 다름)

AI사는 토큰 수에 따라 요금을 청구합니다. 주요 모델 단가 비교:

* 단가는 변경될 수 있습니다. 실제 요금은 각 AI사 콘솔에서 확인하세요.

실제 실수 사례
3가지

이런 실수가 가장 많이 발생합니다. 미리 알아두면 피할 수 있습니다.

📋
노션 공개 페이지에 붙여넣기
메모하려고 노션에 키를 저장했는데, 그 페이지가 "공개"로 설정돼 있었던 경우. 봇이 자동으로 수집해서 수십만 원이 청구된 사례 다수.
💻
GitHub에 코드와 함께 올리기
프로젝트 코드에 키를 직접 써넣고 GitHub에 push한 경우. GitHub이 자동으로 키를 감지하긴 하지만, 감지 전에 이미 수집되는 경우도 있음.
💬
카카오톡·슬랙으로 공유
팀원이나 지인에게 임시로 키를 전달하려고 메신저로 보낸 경우. 채팅 기록이 유출되거나 단체방에 잘못 올라간 사례.
유출됐을 때 즉시 행동 순서
① 콘솔 접속 → ② 해당 키 즉시 삭제 → ③ 새 키 발급
삭제하면 그 키로는 더 이상 요금이 청구되지 않습니다. 패닉하지 말고 순서대로.

4장 · 로컬 AI — LM Studio

LM Studio
4단계로 시작

코드 한 줄 없이 클릭만으로 로컬 AI를 실행합니다.

1

lmstudio.ai에서 무료 설치

Windows·Mac 모두 지원합니다. 설치 파일 약 400MB. 단, 모델은 별도로 수~수십 GB 추가 다운로드가 필요합니다. 넉넉한 저장 공간을 확인하세요.

2

모델 선택 · 내려받기

검색창에서 모델을 골라 다운로드합니다. 내 RAM에 맞는 크기를 선택하세요.
RAM 8GB → 7B 이하 / RAM 16GB → 13B 이하 권장. 처음엔 Llama 3.1 8B를 추천합니다.

3

Developer 탭 → "Start Server" 클릭

LM Studio가 내 컴퓨터 안에 AI 서버를 엽니다. 주소는 http://localhost:1234입니다.

4

BYOK 서비스에 주소 입력

WonGuardian 같은 BYOK 서비스의 설정창에 http://localhost:1234를 입력하면 연결 완료. 인터넷 없이 작동합니다.

키 여러 개,
어떻게 관리하나요?

Claude·GPT·Gemini 키를 모두 발급받으면 관리가 복잡해 보입니다. 실용적인 방법을 소개합니다.

1

키는 용도별로 이름 붙여서 발급

하나의 AI사 계정에서 키를 여러 개 만들 수 있습니다. "wonguardian-key", "vibe2spec-key" 처럼 이름을 붙이면 어디서 얼마나 쓰는지 추적하기 좋습니다.

2

비밀번호 관리앱에 보관

1Password, Bitwarden, Apple 키체인 같은 앱에 저장하세요. 메모장·카카오톡·노션 공개페이지는 절대 금지.

3

키 하나당 월 한도를 설정

각 AI사 콘솔의 Billing 메뉴에서 월 지출 한도를 설정합니다. 예: 월 $5 한도. 이 금액을 넘으면 자동 중지됩니다.

키 여러 개 써도 되나요?
됩니다. 클라우드 AI 키(Claude+Gemini)를 여러 BYOK 서비스에 같이 써도 됩니다.
요금은 각 키별로 합산 청구됩니다. 서비스끼리 간섭하지 않습니다.

FAQ

키가 유출되면 내 돈이 다 나가나요?
월 한도를 설정해 두면 그 이상은 청구되지 않습니다. 유출 즉시 키를 삭제하면 그 순간부터 차단됩니다. 한도 설정을 먼저 하는 게 중요합니다.
LM Studio를 쓰면 성능이 많이 떨어지나요?
일상적인 텍스트 작업(글쓰기, 아이디어 정리, 번역)에는 충분합니다. 복잡한 코드 작성이나 깊은 분석은 클라우드 AI가 더 낫습니다. 처음엔 로컬로 감 잡고, 필요에 따라 클라우드로 이동하는 것을 추천합니다.
키를 여러 BYOK 서비스에 같이 써도 되나요?
됩니다. 하나의 키를 여러 서비스에서 동시에 사용할 수 있습니다. 요금은 전체 사용량이 합산되어 청구됩니다.
Gemini 무료 티어는 얼마나 쓸 수 있나요?
Gemini Flash 무료 티어는 가볍게 쓰는 솔로프레너에게 충분한 양입니다. 정확한 한도는 Google AI Studio 콘솔에서 확인하세요 (변경될 수 있습니다). 단, 무료 티어는 구글이 내 요청을 모델 학습에 활용할 수 있습니다.
브라우저를 바꾸면 키를 다시 입력해야 하나요?
네. BYOK 서비스의 키는 브라우저 localStorage에 저장되기 때문에, 다른 브라우저나 다른 기기에서는 다시 입력해야 합니다. 이건 보안상 의도된 설계입니다.
